📋 Elemen yang Terdaftar di HaxStore

Setiap komponen memanggil HaxStore.requestAvailability() di constructor dan mendaftarkan haxProperties ke store.elementList. Karena itu, begitu editor HAX (haxcms-elements) dimuat, elemen di bawah muncul di pencarian "add element" dan semua propertinya bisa diedit lewat panel HAX.

Cara kerjanya: saat HAX editor aktif di halaman, elemen yang belum terpasang tetap muncul di daftar elemen HAX. Setelah ditarik ke halaman, HAX menulis tag + atribut ke body, sehingga semua konfigurasi (mode, kelas, kd-materi, apps-script-url, questions, dst.) dapat diubah lewat panel properti HAX.

Registrasi HAX terjadi otomatis. Tidak perlu memanggil API HAX secara manual — lihat contoh kode di lib/kuis-ledakan.js (baris ~220): 
globalThis.HaxStore &&
  typeof globalThis.HaxStore.requestAvailability === "function" &&
  (() => { const store = globalThis.HaxStore.requestAvailability();
    store.elementList[ModularQuiz.tag] = ModularQuiz.haxProperties; })();

🛠 Langkah Agar Halaman Bisa Diedit via HAX

#Langkah
1Pasang @haxtheweb/haxcms-elements (atau buka situs HAXcms yang sudah ada, mis. haxme/) — inilah yang menyediakan HAX editor.
2Impor dasbor-kuis pada halaman/theme (atau publish ke npm lalu tambahkan ke appstore HAX via npm run release).
3Buka halaman di HAX editor (modus edit). Semua tag di tabel di atas muncul di pencarian "add element".
4Klik elemen yang sudah ada di halaman → panel properti HAX menampilkan atribut (mode, kelas, kd-materi, apps-script-url, questions, dll.) yang bisa diedit.
5Untuk dasbor penuh, cukup satu <dasbor-kuis>; untuk halaman kuis/forum/tugas standalone, tarik <kuis-ledakan>, <ruang-diskusi>, atau <kirim-tugas> masing-masing.
Catatan repo: package ini tidak menyertakan haxcms-elements sebagai dependensi (editor berat). Registrasi HaxStore di lib/*.js bersifat opsional — bila editor tidak ada, komponen tetap berjalan sebagai elemen Lit biasa.
