Model Kurikulum Merdeka: Formatif tidak sama dengan Sumatif

Dalam Kurikulum Merdeka, penilaian dibagi menjadi dua jalur yang tidak boleh tercampur:

FORMATIF Progress Tracking

Digunakan murni untuk pemantauan perkembangan siswa selama proses belajar. Skor formatif (kuis harian, latihan, observasi) bersifat diagnostik — membantu guru dan siswa melihat di mana perlu remedial atau pengayaan.

Tidak dimasukkan ke dalam rumus perhitungan rapor akhir.

SUMATIF Rapor

Merupakan penilaian akhir yang resmi tercatat di rapor. Hanya asesmen sumatif (Lingkup Materi / LM dan Sumatif Akhir Semester / SAS) yang dipakai untuk menghitung Nilai_Rapor.

Formatif hanya menjadi rujukan pantauan, bukan komponen angka rapor.

Prinsip kunci: Formatif memandu proses, Sumatif mencatat hasil. Engine v6 memastikan kolom rapor hanya diisi dari jalur sumatif, sehingga nilai latihan harian tidak menggembosi atau menggelembungkan rapor siswa.

Rumus Nilai Rapor (Kurikulum Merdeka)

Nilai rapor dihitung murni dari jalur sumatif: gabungan rata-rata Lingkup Materi (bobot 60%) dan Sumatif Akhir Semester (bobot 40%).

Nilai_Rapor = ( Rerata_LM x 0.6 ) + ( SAS x 0.4 )

Contoh Terhitung (data siswa uji)

Skor tiap LM dihitung sebagai rata-rata skor_tulis dan skor_performa:

LMTulisPerformaNilai Akhir LM
LM-18086(80+86)/2 = 83,0
LM-28590(85+90)/2 = 87,5
LM-37585(75+85)/2 = 80,0
LM-47882(78+82)/2 = 80,0
LM-57074(70+74)/2 = 72,0

Rerata_LM = (83,0 + 87,5 + 80,0 + 80,0 + 72,0) / 5 = 402,5 / 5 = 80,5

SAS = sumatif_akhir_semester = 82

Nilai_Rapor = (80,5 x 0.6) + (82 x 0.4) = 48,3 + 32,8 = 81,1
Hasil Nilai_Rapor = 81,1 dengan SAS = 82 akan dipetakan ke Interval_Capaian pada langkah berikutnya.

Interval Capaian (Pengganti Lulus / Tidak Lulus)

Kurikulum Merdeka tidak lagi melabeli siswa "lulus/tidak lulus" pada rapor, melainkan Interval Capaian berdasarkan Nilai_Rapor:

Mencapai TP (>= 75) - Perlu Pengayaan (>= 60) - Perlu Remedial (< 60)
IntervalSyarat Nilai_RaporMakna
Mencapai TP>= 75Tujuan Pembelajaran tercapai, siap lanjut / pengayaan opsional
Perlu Pengayaan>= 60 dan < 75Capaian dasar sudah terpenuhi, perlu diperkaya
Perlu Remedial< 60Belum mencapai TP, perlu remedial/pembelajaran ulang
Pada contoh di atas, Nilai_Rapor = 81,1 >= 75 maka Interval_Capaian = "Mencapai TP". Fungsi tentukanIntervalCapaian(nilaiRapor) menangani pemetaan ini.

Skor Sikap diganti Catatan Anekdot / Observasi Karakter

Untuk dimensi sikap (Profil Pelajar Pancasila), angka diganti dengan narasi deskriptif. Guru mencatat anekdot perilaku nyata, lalu engine menyusun ringkasannya melalui rangkumCatatanSikap().

Contoh data masukan (dua observasi)

Catatan_Anekdot_Sikap:
  2026-08-05 | Gotong Royong   | "Sangat aktif membantu teman
             |                 |  kelompoknya menyelesaikan
             |                 |  konfigurasi Web Component."
  2026-08-10 | Bernalar Kritis | "Mampu memberikan sanggahan
             |                 |  logis disertai bukti
             |                 |  dokumentasi resmi saat diskusi
             |                 |  materi energi biomassa."

Generator narasi (konsep rangkumCatatanSikap)

function rangkumCatatanSikap(catatan) {
  return catatan.map(c =>
    "Pada " + c.tanggal + ", dalam dimensi " + c.dimensi_pancasila + ", " +
    "siswa " + c.perilaku
  ).join(" ");
}

// Hasil:
// "Pada 2026-08-05, dalam dimensi Gotong Royong, siswa sangat
//  aktif membantu teman kelompoknya menyelesaikan konfigurasi
//  Web Component. Pada 2026-08-10, dalam dimensi Bernalar Kritis,
//  siswa mampu memberikan sanggahan logis disertai bukti
//  dokumentasi resmi saat diskusi materi energi biomassa."
Narasi ini ditulis ke kolom Catatan_Perilaku (sheet Catatan_Anekdot_Sikap) dan dapat dirangkum lebih lanjut ke Deskripsi_Capaian pada rapor.

Cara Kerja generateReport

Ketika action=generateReport dipanggil, engine membaca tiga sumber lalu menulis Akumulasi_Nilai_Rapor secara murni (tanpa angka formatif):

1
Baca sumber. Engine mengambil db_asesmen (LM + SAS), Catatan_Anekdot_Sikap, dan Presensi_Administratif.
2
Proses nilai sumatif. prosesNilaiLingkupMateri() menghitung nilai akhir tiap LM, lalu hitungRaporKurikulumMerdeka() menjalankan rumus (Rerata_LM x 0.6) + (SAS x 0.4).
3
Tentukan interval dan narasi. tentukanIntervalCapaian() memetakan nilai ke interval; rangkumCatatanSikap() menyusun deskripsi sikap.
4
Hasilkan rapor. generateLaporanSiswa() menggabungkan semua ke dalam satu baris Akumulasi_Nilai_Rapor (menimpa baris lama sehingga idempoten).
Fungsi EnginePeran
prosesNilaiLingkupMateriHitung nilai akhir LM-1 sampai LM-5 dan Rerata_LM
hitungRaporKurikulumMerdekaRumus (Rerata_LM x 0.6) + (SAS x 0.4) menghasilkan Nilai_Rapor
tentukanIntervalCapaianPetakan Nilai_Rapor ke Mencapai TP / Pengayaan / Remedial
rangkumCatatanSikapUbah anekdot menjadi narasi deskriptif sikap
generateLaporanSiswaRangkai semua hasil lalu tulis Akumulasi_Nilai_Rapor

Catatan: Rerata_LM pada rumus adalah 80,5. Pada data uji STS kosong, sehingga engine menggunakan 80,5 (bukan rata-rata yang menyertakan STS). Sesuaikan narasi dengan kolom yang tersedia di spreadsheet.

Langkah Deploy

1
Salin backend. Salin seluruh isi codev6.gs ke editor Apps Script yang terikat pada spreadsheet kamu.
2
Deploy. Pilih Deploy > New deployment lalu tipe Web app; Execute as: Me; Who has access: Anyone.
3
Tempel URL. Salin URL /exec hasil deploy, lalu tempel ke atribut apps-script-url pada <dasbor-kuis> (misalnya <dasbor-kuis apps-script-url="https://script.google.com/.../exec">).
4
Uji. Panggil ?action=generateReport (atau kirim payload generateReport via doPost) untuk mengisi Akumulasi_Nilai_Rapor, lalu pantau di Mode Guru.
Backend codev6.gs dan skrip penyalin disiapkan oleh agen lain — tutorial ini hanya menjelaskan cara penggunaan dan alur datanya.
