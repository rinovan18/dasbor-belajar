🎛️ Tiga Mode Tampilan

Properti mode menentukan seluruh tab yang terlihat — siswa tidak akan pernah melihat tab milik guru (dan sebaliknya) kecuali halaman admin sengaja menampilkan tombol pindah mode.

modePenggunaTab yang tampilFungsi utama
guruGuru / Wali Kelas Pantauan Guru · Leaderboard · Peringkat Nilai Bimbingan Kelas · Dashboard Pembelajaran · Input Nilai · Evaluasi Kuis · Ruang Diskusi · Edit Soal · Atur Monitoring kelas + leaderboard + edit & ekspor nilai + atur konfigurasi
dosen(alias Guru) — diperlakukan sebagai guru — Label lama; kini memakai tab guru (Peringkat Nilai Bimbingan Kelas di tab tersendiri)
siswaSiswa Dashboard Pembelajaran · Hasil & Nilai · Evaluasi Kuis · Ruang Diskusi Hasil nilai pribadi + aktivitas mandiri (baca, kuis, diskusi)
🔒 Mode tersembunyi secara default. Tombol pindah mode (Guru/Siswa) di navbar disembunyikan kecuali properti allow-mode-switch diaktifkan. Ini mencegah siswa beralih ke tampilan guru (dan sebaliknya). Set mode lewat atribut mode pada tag, bukan lewat tombol.

🏫 Properti HAX — <dasbor-kuis>

Properti (atribut)TipeModeDeskripsi
apps-script-urlStringSemua Wajib. URL /exec Google Apps Script (backend codev5.gs).
modeStringSemua guru | dosen (alias guru) | siswa. Menentukan tab & data yang tampil.
kd-materiStringSemua Wajib. Kode pertemuan/topik, mis. Pertemuan 1.
kelasStringGuru Filter roster/leaderboard per kelas, mis. XI-1; kosongkan untuk semua.
allow-mode-switchBooleanGuru Menampilkan tombol pindah mode di navbar. Default tersembunyi.
student-idStringSiswa ID siswa (otomatis terisi event quiz-user-login / profil tersimpan).
nama-siswaStringSiswa Nama siswa untuk identitas & log aktivitas.
nisStringSiswa NIS siswa (sheet Users).
absenStringSiswa Nomor absen siswa.
judul-kuisStringGuru Judul kartu kuis pada tab Evaluasi Kuis.
questionsJSONGuru Soal kuis (dapat diedit guru di HAX editor maupun tab Edit Soal). Kosongkan agar otomatis dimuat dari sheet Bank Soal.
shuffle-choicesBooleanGuru Mengacak pilihan jawaban tiap mulai kuis.
hide-answersBooleanGuru Menyembunyikan umpan balik benar/salah (mode ujian).

📝 Properti HAX — <kuis-ledakan>

Kuis AKM interaktif (PG, PG Kompleks, Benar/Salah, Menjodohkan, Isian Singkat). Hasil dikirim ke action=logActivity baik saat berada di dalam dasbor maupun dipakai standalone.

Properti (atribut)TipeDeskripsi
judulStringJudul kartu kuis.
apps-script-urlStringURL /exec untuk mengirim hasil + memuat Bank Soal.
kd-materiStringKode topik pada log aktivitas.
modeStringguru (bisa ulang) | siswa (terkunci setelah selesai).
questionsJSONArray soal; format lama [{q,a,b,c,k}] juga didukung.
shuffle-choicesBooleanAcak pilihan jawaban.
hide-answersBooleanSembunyikan umpan balik benar/salah.
hide-confettiBooleanNonaktifkan animasi confetti.
student-id, student-name, student-nis, student-absen, student-kelasStringIdentitas siswa untuk log (diisi otomatis dari sesi login).
 
<kuis-ledakan
  judul="Evaluasi Kuis Interaktif"
  mode="siswa"
  kd-materi="Pertemuan 1"
  apps-script-url="https://script.google.com/macros/s/XYZ/exec"
  questions='[{"question":"Apa ibu kota Indonesia?","choices":["Bandung","Jakarta","Surabaya"],"correctIndex":1}]'>
</kuis-ledakan>

🔗 Properti Komponen Pendukung

quiz-user-auth

Properti (atribut)TipeDeskripsi
apps-script-urlStringWajib. URL /exec (action=register|login|verify).
auto-loginBooleanCoba login otomatis bila ada sesi tersimpan.

ruang-diskusi (Ruang Diskusi)

Properti (atribut)TipeDeskripsi
forum-api-urlStringWajib. URL /exec backend forum/tugas (lib/code-forum-tugas.gs, sheet Forum Log).
apps-script-urlStringURL /exec utama untuk log aktivitas discussion.
forum-topicStringTopik diskusi.
sheet-nameStringNama pertemuan / kdMateri filter komentar.
view-modeStringstudent (default) / lecturer (muncul tombol Hapus).
hide-deleteBooleanSembunyikan tombol Hapus.

kirim-tugas (Pengumpulan Tugas)

Properti (atribut)TipeDeskripsi
forum-api-urlStringWajib. URL /exec backend forum/tugas (lib/code-forum-tugas.gs, sheet Tugas Log).
apps-script-urlStringURL /exec utama untuk log aktivitas assignment.
assignment-titleStringJudul tugas.
assignment-instructionStringInstruksi pengerjaan.
sheet-nameStringNama pertemuan / kdMateri (kunci localStorage status).

sistem-kehadiran (Dashboard Pembelajaran / Ruang Baca)

Properti (atribut)TipeDeskripsi
apps-script-urlStringURL /exec untuk riwayat aktivitas server.
kd-materiStringKode topik pada log.
student-idStringID siswa.
nama-siswaStringNama siswa.
modeStringWarisan dari dasbor (guru/siswa).
questionsJSONSoal mini-kuis internal (opsional).
🔄 Sinkronisasi. Semua aktivitas (reading/quiz/forum) masuk ke antrean lokal a3_v5_sync_queue dengan id_log idempoten, lalu dikirim masal via action=logActivity. Antrean dikirim ulang saat koneksi online, jendela fokus, atau muat ulang.

🧪 Contoh HTML Siap Pakai

1 · Halaman Guru (dengan tombol pindah mode untuk admin)

<dasbor-kuis
  mode="guru"
  allow-mode-switch
  kelas="XI-1"
  kd-materi="Pertemuan 1"
  apps-script-url="https://script.google.com/macros/s/XYZ/exec">
</dasbor-kuis>

2 · Halaman Guru — Peringkat Nilai Bimbingan Kelas (tab Guru)

<dasbor-kuis
  mode="guru"
  kelas="XI-1"
  kd-materi="Pertemuan 1"
  apps-script-url="https://script.google.com/macros/s/XYZ/exec">
</dasbor-kuis>

3 · Halaman Siswa (mode terkunci, tanpa tombol pindah)

<dasbor-kuis
  mode="siswa"
  student-id="STD-65108053"
  nama-siswa="Andy Yulianto"
  nis="65108053"
  absen="21"
  kelas="XI-1"
  kd-materi="Pertemuan 1"
  apps-script-url="https://script.google.com/macros/s/XYZ/exec">
</dasbor-kuis>

4 · Guru mengedit soal lewat HAX (properti questions)

<dasbor-kuis mode="guru" apps-script-url="https://script.google.com/macros/s/XYZ/exec"
  questions='[
    {"question":"Apa kegunaan connectedCallback pada LitElement?","choices":["Inisialisasi","Deteksi saat elemen masuk DOM","Hapus listener"],"correctIndex":1},
    {"question":"PG Kompleks — pilih semua pernyataan benar","type":"pgk","statements":[{"text":"id_log mencegah duplikat","answer":true},{"text":"flushQueue mengosongkan antrean lokal","answer":true}],"points":2}
  ]' />
💡 Alur cepat: ubah mode untuk peran berbeda → isi apps-script-url + kd-materi → untuk guru, edit soal lewat questions di HAX editor → arahkan siswa ke halaman mode="siswa" (tanpa allow-mode-switch) sehingga tampilan guru tersembunyi.
