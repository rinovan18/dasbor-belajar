📊 Tutor: Akumulasi Nilai Rapor

Cara kerja sheet Akumulasi Nilai Rapor — satu baris per siswa berisi kehadiran, UH, UTS, UAS, Nilai Akhir & Grade, dihasilkan generateReport dan dibaca getScores di Mode Siswa.

← Demo utama (index.html) 🗂 Hubungan Sheet 📚 Tutor Rangkuman 🔎 Hasil Cek Perubahan

🔄 Alur Data — hingga menjadi Nilai Rapor

1
Skor kuis dicatat ke db_nilai. Kuis dikirim via action=logActivity dengan type=quiz; deskripsi JSON berisi {"score":…,"kategori":"ulangan_harian|uts|uas|formatif|sumatif"}.
2
Kehadiran dicatat ke db_kehadiran. action=saveAttendanceComplete menulis/update baris per siswa per hari (UPSERT).
3
Guru memanggil action=generateReport. Backend menghitung rata-rata UH, skor tertinggi UTS/UAS, rata-rata kehadiran, lalu menulis sheet Akumulasi Nilai Rapor.
4
Siswa melihat hasilnya. Mode Siswa memanggil action=getScores&studentId=… yang membaca Akumulasi Nilai Rapor (+ Nilai Manual untuk override).
Boosting kehadiran: sejak pembaruan terbaru, kolom Kehadiran (skala 100) diisi rata-rata Kehadiran (%) dari db_kehadiran, bukan angka mati 0 — sehingga siswa yang rajin hadir langsung mendapat poin penuh pada komponen kehadiran Nilai Akhir.

Nilai Akhir = (Kehadiran×1 + Rata-rata UH×3 + UTS×2 + UAS×2) ÷ 8

✍️ Nilai Manual (Override)

Guru dapat mengoreksi UTS/UAS/kehadiran/UH/sikap/keterampilan/nilai akhir lewat sheet Nilai Manual:

GET {FORM_API}?action=setManualScore&studentId=STD-…&kategori=uts&skor=90
GET {FORM_API}?action=setManualScore&studentId=STD-…&kategori=uas&skor=88

🚀 Cara Menjalankan

1. Pastikan sheet Akumulasi Nilai Rapor, db_nilai, db_kehadiran, Users ada.

2. Tempel URL /exec ke apps-script-url (lihat DATA-CONTOH.md).

3. Kirim kehadiran otomatis: ?action=saveAttendanceComplete&studentId=…&kehadiran=100&kdMateri=….

4. Panggil ?action=generateReport, lalu siswa melihat nilai akhir di Mode Siswa (getScores).
