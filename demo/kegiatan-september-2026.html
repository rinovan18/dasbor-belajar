💡 Klik kartu untuk melihat jawaban di sisi belakang

Apa itu Web Component?
Standar browser untuk membuat elemen HTML kustom yang dapat digunakan ulang dengan enkapsulasi DOM dan styling.
Apa fungsi Shadow DOM?
Mengisolasi DOM dan CSS komponen dari elemen lain di halaman, mencegah konflik styling.
Apa itu Custom Elements?
API JavaScript untuk mendefinisikan elemen HTML baru dengan behavior dan properti sendiri.
Apa itu LitElement?
Base class ringan untuk membuat Web Components dengan reactive properties dan templating deklaratif.
Apa kepanjangan HTML?
HyperText Markup Language — bahasa markup untuk struktur halaman web.
Apa kepanjangan CSS?
Cascading Style Sheets — bahasa styling untuk mendesain tampilan halaman web.
HAX adalah singkatan dari?
Hybrid Authoring eXperience — platform authoring konten web modern.
Apa kegunaan Google Apps Script?
Platform scripting berbasis cloud untuk mengotomasi dan memperluas produk Google seperti Sheets, Docs, dan Forms.
