# Timer Fix Plan for Latihan-Kuis

## Issue Summary
The latihan-kuis timer and navigation are stuck on initial start/refresh due to race conditions and improper state synchronization between latihan-kuis and timer-kuis components.

## Root Cause Analysis

### Primary Issues:
1. **Timer Resume Logic Flaw** (`latihan-kuis.js:295-302`)
   - `_cobaResumeTimer()` fails when `_bacaSisaWaktu()` returns `null` or `≤ 0`
   - No handling for expired or missing timer data
   - User starts fresh but sees "stuck" state

2. **Timer Component Race Condition** (`timer-kuis.js:50-60`)
   - `connectedCallback()` resets `_remaining` to full duration
   - Overrides `_resumeRemaining` passed by parent
   - Timer starts immediately regardless of parent state

3. **Property/State Variable Mismatch** (`latihan-kuis.js:633-636`)
   - Passing `_resumeRemaining` as `duration` to child component
   - Inconsistent synchronization between parent and child timer state
   - Navigation buttons don't respect timer state

### Secondary Issues:
4. **Missing Navigation Validation**
   - No checks for timer state before allowing navigation
   - User can navigate while timer is stuck
   - State inconsistency between components

## Solution Design

### 1. Fix Timer Resume Logic
**File**: `latihan-kuis.js`

```javascript
// Fix _cobaResumeTimer() to handle all edge cases
cobaResumeTimer() {
  const sisa = this._bacaSisaWaktu();
  const kuota = this.maxRetake === 0 || this._attemptKe < this.maxRetake + 1;
  
  // Fix: Handle null/undefined and proper quota check
  if (kuota && sisa != null && sisa > 0) {
    this._mulai = true;
    this._resumeRemaining = sisa;
  }
}

// Fix _bacaSisaWaktu() to return consistent values
_bacaSisaWaktu() {
  if (!this.studentId || !this.kdMateri) return 0;  // Return 0 instead of null
  try {
    const d = JSON.parse(globalThis.localStorage.getItem(this._timerKey()) || "null");
    if (!d) return 0;  // Handle null data case
    const sisa = d.duration - Math.floor((Date.now() - d.start) / 1000);
    return sisa > 0 ? sisa : 0;  // Ensure non-negative
  } catch (_) {
    return 0;  // Consistent return value
  }
}
```

### 2. Fix Timer Component Initialization
**File**: `timer-kuis.js`

```javascript
// Fix connectedCallback() to respect parent's _resumeRemaining
connectedCallback() {
  super.connectedCallback();
  
  // Fix: Prioritize _resumeRemaining from parent
  if (this._resumeRemaining != null && !isNaN(this._resumeRemaining)) {
    this._remaining = this._resumeRemaining;
  } else if (this.remaining != null && !isNaN(this.remaining)) {
    this._remaining = this.remaining;
  } else {
    this._remaining = this.duration;
  }
  
  // Only autostart if timer should actually run
  if (this.autostart && this._remaining > 0) {
    this.start();
  }
}
```
