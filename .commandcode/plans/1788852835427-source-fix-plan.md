# Comprehensive Timer Fix & State Persistence Plan

## Overview
Fix timer freeze, state persistence across browser close/reopen, and ensure proper logging of quiz start/finish events to `db_aktivitas` and `db_asesmen`.

## Source Files to Modify
All changes apply to `elements/dasbor-kuis/lib/`:
1. `latihan-kuis.js`
2. `timer-kuis.js`
3. `kuis-ledakan.js`

## Phase 1: Already Implemented (Plan A)
- `_bacaSisaWaktu()` returns 0 instead of null
- `_cobaResumeTimer()` handles null/undefined correctly
- `connectedCallback()` in timer-kuis.js prioritizes `_resumeRemaining`
- `_canNavigateTo()` validation added
- `_goToQuestion()` calls `_canNavigateTo()`

## Phase 2: Remaining (Plan B)

### 2.1 Remove Navigation Restriction
In `kuis-ledakan.js`, remove `if (!this._started && index !== 0) return false;` from `_canNavigateTo()` to allow free navigation before quiz start.

### 2.2 Add Browser Visibility Event Handler
In `latihan-kuis.js`, add `_onVisibilityChange()` to save timer state when user switches tabs/app.

### 2.3 Add Quiz Start/Finish Logging
Add `_logMulaiKuis()` and `_logSelesaiKuis()` to persist start/finish timestamps in localStorage for spreadsheet verification.

### 2.4 Sync & Build
Run `npm run sync` then `npm run build` from `haxto/custom`.

## Implementation Steps
1. Edit `elements/dasbor-kuis/lib/kuis-ledakan.js` to remove navigation restriction
2. Edit `elements/dasbor-kuis/lib/latihan-kuis.js` to add visibility handler and logging
3. Run `npm run sync`
4. Run `npm run build`
5. Test: start quiz, switch tab, reopen, verify timer resumes
6. Test: start quiz, finish quiz, verify logs in db_aktivitas/db_asesmen
