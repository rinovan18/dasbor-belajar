How to Develop

Anda dapat mengedit halaman ini dengan memodifikasi index.html
Untuk mengedit tag dasbor-kuis, modifikasi dasbor-kuis.js.

Properti HAX (Guru, Dosen & Siswa)

  • mode — guru (admin lengkap, termasuk Peringkat Nilai Bimbingan) / siswa (hasil nilai)
  • allow-mode-switch — tampilkan tombol pindah mode (default tersembunyi)
  • apps-script-url — URL /exec Apps Script
  • kd-materi — kode pertemuan
  • kelas — filter kelas guru / kelas siswa
  • student-id, nama-siswa, nis, absen — identitas siswa
  • judul-kuis, questions, shuffle-choices, hide-answers — konfigurasi kuis oleh guru

Properti HAX (kuis-ledakan)

  • judul — judul kartu kuis
  • mode — guru (bisa ulangi) / siswa (kunci hasil)
  • kd-materi — kode pertemuan pada log aktivitas
  • apps-script-url — URL /exec Apps Script (action=logActivity)
  • questions — JSON array soal AKM: PG [{ question, choices, correctIndex }], PG kompleks correctAnswers:[0,2], PGK {type:"pgk", statements:[{text,answer}]}, menjodohkan {type:"matching", leftItems, rightItems, correctPairs}, isian {type:"shortAnswer", acceptedAnswers}; format lama [{ q, a, b, c, k }] tetap didukung

Properti HAX (quiz-user-auth)

  • apps-script-url — URL /exec Apps Script (action=register|login|verify)
